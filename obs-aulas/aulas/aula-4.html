    4.1

    Dataset dourado e eval offline

    Conceito
    Capítulo 1 · A política inventada

    Como provar que a nova versão é melhor?

    O agente disse que a troca é em 15 dias; a política é 30. A equipe corrige o prompt, mas como saber se não quebrou outra coisa?

    Tipos de avaliação

    TipoExemploPrós / contras
    Determinísticachamou consultar_pedido? resposta contém “30 dias”?barata e estável / rígida
    Trajetóriaferramentas certas, na ordem certa, sem loopspega erro de raciocínio do agente
    LLM-as-judgea resposta é fiel às ferramentas?flexível / custa e precisa calibrar
    Humanaespecialista revisa amostrapadrão-ouro / lenta e cara

    Dataset dourado

    • Casos representativos: perguntas reais (de traces!), com o resultado esperado.
    • Cubra o caminho feliz, os casos difíceis e os que já falharam.
    • Versione junto com o código; cresça a cada incidente.
    • Comece pequeno (dezenas) e bem rotulado.

    2. O juiz (usado aqui e no exercício 4.2):

      terminal

"""LLM como juiz: dá nota de 0 a 1 para a resposta do agente, com base no que as ferramentas retornaram."""
import json, os
from openai import OpenAI

juiz = OpenAI(base_url=os.getenv("LLM_BASE_URL"), api_key=os.getenv("LLM_API_KEY"))
MODELO_JUIZ = os.getenv("JUIZ_MODEL", os.getenv("LLM_MODEL", "openai/gpt-4.1-mini"))
RUBRICA = """Você avalia respostas de um agente de atendimento de loja.
Critérios: (1) a resposta atende à pergunta; (2) não inventa fatos: prazos, valores e status devem vir das observações das ferramentas;
(3) se não havia como resolver, encaminhou para um humano.
Responda só com JSON: {"nota": número de 0 a 1, "motivo": "uma frase"}"""


def avaliar(pergunta, resposta, observacoes):
    conteudo = (f"Pergunta: {pergunta}\nObservações das ferramentas: {observacoes or 'nenhuma'}\n"
                f"Resposta do agente: {resposta}")
    r = juiz.chat.completions.create(model=MODELO_JUIZ, temperature=0,
                                     messages=[{"role": "system", "content": RUBRICA},
                                               {"role": "user", "content": conteudo}])
    texto = r.choices[0].message.content.strip().removeprefix("```json").strip("` \n")
    try:
        d = json.loads(texto)
        return max(0.0, min(1.0, float(d["nota"]))), str(d.get("motivo", ""))
    except (ValueError, KeyError):
        return 0.0, f"juiz respondeu fora do formato: {texto[:80]}"
EOF

    3. O avaliador: para cada caso, checa a ferramenta, o conteúdo e a nota do juiz:

      terminal
      cat > eval_offline.py <<'EOF'
"""Eval offline: roda o dataset dourado contra o agente e reprova se a qualidade cair abaixo do limite."""
import json, sys
import httpx
from juiz import avaliar

LIMITE = float(sys.argv[1]) if len(sys.argv) > 1 else 0.8
casos = [json.loads(l) for l in open("dataset.jsonl")]
linhas, notas = [], []
for c in casos:
    r = httpx.post("http://localhost:8000/chat", json={"texto": c["pergunta"]}, timeout=120).json()
    resposta = r.get("resposta") or ""
    ferramenta_ok = c["ferramenta"] in r.get("ferramentas", [])
    conteudo_ok = all(t.lower() in resposta.lower() for t in c["contem"])
    nota_juiz, motivo = avaliar(c["pergunta"], resposta, r.get("ferramentas"))
    nota = (ferramenta_ok + conteudo_ok + nota_juiz) / 3
    notas.append(nota)
    linhas.append(f"{c['id']:<4} ferramenta={'ok ' if ferramenta_ok else 'ERR'} conteudo={'ok ' if conteudo_ok else 'ERR'}"
                  f" juiz={nota_juiz:.2f} nota={nota:.2f}  {motivo[:60]}")
print("\n".join(linhas))
media = sum(notas) / len(notas)
print(f"\nmédia={media:.2f} limite={LIMITE}")
sys.exit(0 if media >= LIMITE else 1)
EOF

    4. Rode e veja o código de saída (é o que o CI usaria):

      terminal
      python eval_offline.py 0.8; echo "exit=$?"
    Resultado esperado
    • Uma linha por caso com ferramenta, conteudo, juiz e nota.
    • A média final e exit=0 (aprovado) ou exit=1 (reprovado).
    O que aprendemos com este exercício?
    • Eval offline é teste de regressão para comportamento não determinístico.
    • O código de saída permite bloquear o deploy no pipeline (disciplina de Deploy e CI/CD).
    Desafio

    Suba o agente com PROMPT_VERSAO=v2 (prompt sem instruções de ferramentas) e rode o eval de novo. A versão seria bloqueada?

    4.2

    LLM como juiz

    Conceito
    Capítulo 2 · Quem avalia o avaliador?

    O juiz também erra

    Um LLM avaliando outro é rápido e escala, mas tem vieses: prefere respostas longas, a própria família de modelos e a primeira opção.

    Boas práticas de LLM-as-judge

    Rubrica

    • Critérios explícitos e binários quando possível
    • Saída estruturada (JSON)

    Contexto

    • Dê ao juiz as observações das ferramentas
    • Fidelidade = comparar resposta com fatos

    Calibração

    • Compare com rótulos humanos
    • Meça concordância antes de confiar
    Prática
    Exercício 4.2

    Calibrando o juiz

    ~20 min

    Testar o juiz contra casos com rótulo conhecido.

    1. Rode o juiz em três respostas, uma correta, uma inventada e uma evasiva:

      terminal
      python - <<'EOF'
from juiz import avaliar
obs = ["buscar_politica: Trocas em até 30 dias após a entrega, com o produto sem uso e na embalagem original."]
for resposta in ["Você pode trocar em até 30 dias após a entrega, sem uso e na embalagem.",
                 "A troca só é aceita em até 15 dias após a compra.",
                 "Não sei, procure a loja."]:
    print(avaliar("Posso trocar depois de 20 dias?", resposta, obs), "<-", resposta)
EOF
    Resultado esperado
    • Nota alta para a correta, baixa para a inventada (15 dias) e baixa ou média para a evasiva.
    O que aprendemos com este exercício?
    • O juiz só detecta alucinação se receber os fatos (observações).
    • Calibrar com poucos exemplos rotulados já mostra se dá para confiar.
    Desafio

    Troque o modelo do juiz (JUIZ_MODEL) e veja se as notas mudam.

    4.3

    Eval online e feedback

    Conceito
    Capítulo 3 · Produção é o dataset real

    Avaliar sem atrasar o cliente

    Em produção, o juiz roda fora do caminho da resposta, numa amostra das conversas. A nota vira métrica, e o span do juiz aponta para o trace avaliado.

    Eval online ligado ao trace

    Conversatrace invoke_agent
    →
    Amostra 30%thread em segundo plano
    →
    Juizspan evaluate com link ao trace
    →
    Sinaismétrica agente.eval.nota + log com trace avaliado
    • Atributos gen_ai.evaluation.name e gen_ai.evaluation.score.value (convenções GenAI).
    • Feedback do usuário (👍/👎) com o trace_id: o mais barato dos sinais de qualidade.

    Referências: OpenTelemetry · GenAI semantic conventions.

    Prática
    Exercício 4.3

    Eval online por amostragem e feedback

    ~30 min

    Adicionar ao agente o juiz em segundo plano e o endpoint de feedback.

"""Agente de atendimento da Loja: loop de LLM com ferramentas, traces, métricas, chaos e eval online."""
import json, logging, os, random, threading, time
from fastapi import FastAPI
from pydantic import BaseModel
from openai import OpenAI
from opentelemetry import trace, metrics
from opentelemetry.trace import Status, StatusCode
from opentelemetry.instrumentation.openai_v2 import OpenAIInstrumentor
from telemetria import configurar
from ferramentas import FERRAMENTAS, executar
from juiz import avaliar

configurar("atendimento")
OpenAIInstrumentor().instrument()
tracer = trace.get_tracer("loja.agente")
meter = metrics.get_meter("loja.agente")
log = logging.getLogger("agente")

MODELO = os.getenv("LLM_MODEL", "openai/gpt-4.1-mini")
llm = OpenAI(base_url=os.getenv("LLM_BASE_URL"), api_key=os.getenv("LLM_API_KEY"))
PRECO_ENTRADA = float(os.getenv("PRECO_ENTRADA_1M", "0.40")) / 1e6   # USD por token
PRECO_SAIDA = float(os.getenv("PRECO_SAIDA_1M", "1.60")) / 1e6
PROMPTS = {
    "v1": ("Você é o agente de atendimento da Loja. Responda em português, em no máximo 3 frases. "
           "Use consultar_pedido para pedidos e buscar_politica para trocas, devoluções, frete e garantia. "
           "Nunca invente prazos ou valores: use só o que as ferramentas retornarem. "
           "Se não conseguir resolver, use abrir_chamado."),
    "v2": "Você é um atendente simpático. Responda rápido, sem enrolar.",
}
PROMPT_VERSAO = os.getenv("PROMPT_VERSAO", "v1")
CHAOS_LATENCIA = float(os.getenv("CHAOS_LATENCIA_S", "0"))
CHAOS_FALHA = float(os.getenv("CHAOS_FALHA_FERRAMENTA", "0"))
AMOSTRA_EVAL = float(os.getenv("EVAL_AMOSTRA", "0.3"))

conversas = meter.create_counter("agente.conversas", unit="{conversa}", description="Conversas por resultado")
passos_h = meter.create_histogram("agente.passos", unit="{passo}", description="Chamadas ao LLM por conversa")
custo_c = meter.create_counter("agente.custo", unit="USD", description="Custo estimado em tokens")
ferr_c = meter.create_counter("agente.ferramenta.chamadas", unit="{chamada}", description="Chamadas de ferramenta")
nota_h = meter.create_histogram("agente.eval.nota", unit="1", description="Nota do juiz (0 a 1)")
feedback_c = meter.create_counter("agente.feedback", unit="{voto}", description="Feedback do usuário")

app = FastAPI()


class Pergunta(BaseModel):
    texto: str


class Feedback(BaseModel):
    trace_id: str
    util: bool


def chamar_llm(msgs, attrs):
    if CHAOS_LATENCIA:
        time.sleep(CHAOS_LATENCIA)
    r = llm.chat.completions.create(model=MODELO, messages=msgs, tools=FERRAMENTAS, temperature=0)
    custo_c.add(r.usage.prompt_tokens * PRECO_ENTRADA + r.usage.completion_tokens * PRECO_SAIDA, attrs)
    return r.choices[0].message


def chamar_ferramenta(chamada):
    nome = chamada.function.name
    with tracer.start_as_current_span(f"execute_tool {nome}") as s:
        s.set_attribute("gen_ai.operation.name", "execute_tool")
        s.set_attribute("gen_ai.tool.name", nome)
        s.set_attribute("gen_ai.tool.call.id", chamada.id)
        try:
            if random.random() < CHAOS_FALHA:
                raise TimeoutError("sistema de pedidos não respondeu")
            resultado = executar(nome, json.loads(chamada.function.arguments or "{}"))
            ferr_c.add(1, {"gen_ai.tool.name": nome, "status": "ok"})
        except Exception as e:
            s.record_exception(e)
            s.set_status(Status(StatusCode.ERROR, str(e)))
            ferr_c.add(1, {"gen_ai.tool.name": nome, "status": "erro"})
            log.error("ferramenta %s falhou: %s", nome, e)
            resultado = f"erro: {e}"
        return resultado


def avaliar_em_segundo_plano(contexto, pergunta, resposta, observacoes):
    # Roda fora do caminho da resposta; o span do juiz aponta (link) para o trace da conversa
    with tracer.start_as_current_span("evaluate atendimento", links=[trace.Link(contexto)]) as s:
        nota, motivo = avaliar(pergunta, resposta, observacoes)
        s.set_attribute("gen_ai.evaluation.name", "correcao")
        s.set_attribute("gen_ai.evaluation.score.value", nota)
        nota_h.record(nota, {"prompt.versao": PROMPT_VERSAO})
        log.info("eval correcao=%.2f motivo=%s trace_avaliado=%s", nota, motivo,
                 format(contexto.trace_id, "032x"))


@app.post("/chat")
def chat(p: Pergunta):
    attrs = {"gen_ai.request.model": MODELO, "prompt.versao": PROMPT_VERSAO}
    with tracer.start_as_current_span("invoke_agent atendimento") as span:
        span.set_attribute("gen_ai.operation.name", "invoke_agent")
        span.set_attribute("gen_ai.agent.name", "atendimento")
        span.set_attribute("prompt.versao", PROMPT_VERSAO)
        trace_id = format(span.get_span_context().trace_id, "032x")
        log.info("pergunta recebida: %s", p.texto)
        msgs = [{"role": "system", "content": PROMPTS[PROMPT_VERSAO]}, {"role": "user", "content": p.texto}]
        usadas, observacoes = [], []
        try:
            for passo in range(1, 6):
                m = chamar_llm(msgs, attrs)
                if not m.tool_calls:
                    break
                msgs.append(m.model_dump(exclude_none=True))
                for chamada in m.tool_calls:
                    usadas.append(chamada.function.name)
                    saida = chamar_ferramenta(chamada)
                    observacoes.append(f"{chamada.function.name}: {saida}")
                    msgs.append({"role": "tool", "tool_call_id": chamada.id, "content": saida})
            else:
                raise RuntimeError("limite de 5 passos atingido")
        except Exception as e:
            span.record_exception(e)
            span.set_status(Status(StatusCode.ERROR, str(e)))
            conversas.add(1, {**attrs, "resultado": "falha"})
            log.error("conversa falhou: %s", e)
            return {"resposta": "Tive um problema agora. Tente de novo em instantes.", "ferramentas": usadas,
                    "trace_id": trace_id}
        resultado = "escalado" if "abrir_chamado" in usadas else "resolvido"
        span.set_attribute("agente.resultado", resultado)
        span.set_attribute("agente.passos", passo)
        conversas.add(1, {**attrs, "resultado": resultado})
        passos_h.record(passo, attrs)
        log.info("conversa %s em %d passos, ferramentas=%s", resultado, passo, usadas)
        if random.random() < AMOSTRA_EVAL:
            threading.Thread(target=avaliar_em_segundo_plano,
                             args=(span.get_span_context(), p.texto, m.content, observacoes)).start()
        return {"resposta": m.content, "ferramentas": usadas, "trace_id": trace_id}


@app.post("/feedback")
def feedback(f: Feedback):
    feedback_c.add(1, {"util": str(f.util).lower(), "prompt.versao": PROMPT_VERSAO})
    log.info("feedback util=%s trace_avaliado=%s", f.util, f.trace_id)
    return {"ok": True}
EOF
