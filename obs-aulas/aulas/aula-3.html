Aula 03 · Métricas e KPIs

Métricas técnicas e KPIs de negócio para agentes

Traces explicam uma conversa; métricas mostram todas. Você lê as métricas GenAI do OpenTelemetry (tokens e latência), cria métricas próprias do agente (resultado da conversa, passos, custo, ferramentas), gera carga controlada e calcula com PromQL os KPIs que a diretoria pergunta: taxa de resolução, custo por conversa resolvida e escalonamento para humanos.

Tópicos
    3.1

    Golden signals de LLM

    Conceito
    Capítulo 1 · A diretoria quer números

    Está rápido? Está caro? Está funcionando?

    Uma semana depois, a diretoria pede um relatório do agente. Traces não respondem “quanto”: para isso existem métricas.

    Sinais técnicos de um serviço com LLM

    SinalMétricaObservação
    Latênciagen_ai.client.operation.duration (histograma)p50/p95/p99; TTFT em streaming
    Tráfegorequisições, conversas por minutobase de capacidade e limites (rate limit)
    ErrosHTTP 429/5xx, falhas de ferramenta, limite de passos429 = cota do provedor
    Saturação / consumogen_ai.client.token.usage (histograma)tokens de entrada × saída, janela de contexto

    Referências: GenAI metrics.

    Histogramas e percentis

    • Média esconde a cauda: 95% das chamadas em 1 s e 5% em 20 s dá média ~2 s.
    • Histograma guarda contagens por faixa (_bucket); histogram_quantile estima o percentil.
    • Sempre por janela: rate(...[5m]).
    promql
    histogram_quantile(0.95, sum by (le) (rate(gen_ai_client_operation_duration_seconds_bucket[5m])))
    3.2

    Métricas do agente e custo

    Conceito
    Capítulo 2 · O que o provedor não mede

    Resolver o problema do cliente é a métrica que importa

    Tokens e latência vêm prontos. Mas “o cliente foi atendido?” e “quanto custou cada atendimento?” só o seu código sabe.

    Métricas que vamos criar

    MétricaTipoAtributos
    agente.conversascounterresultado (resolvido, escalado, falha), modelo, prompt.versao
    agente.passoshistogramamodelo, prompt.versao
    agente.custo (USD)countermodelo, prompt.versao
    agente.ferramenta.chamadascountergen_ai.tool.name, status

    Cardinalidade

    Boa

    • resultado, modelo, ferramenta, versão do prompt
    • poucos valores possíveis

    Perigosa

    • user_id, trace_id, texto da pergunta
    • cada valor cria uma série nova

    Regra

    • ID vai para trace e log
    • Métrica agrega; trace detalha

    Custo de LLM

    • custo = tokens_entrada × preço_entrada + tokens_saída × preço_saída
    • Saída costuma custar 4× a entrada; contexto longo pesa na entrada.
    • No lab, o GitHub Models é gratuito: calculamos o custo equivalente pelo preço de lista (variáveis PRECO_ENTRADA_1M e PRECO_SAIDA_1M).
    • KPI que importa: custo por conversa resolvida, não custo por token.

    1. Nova versão do agente:

      cd ~/obs/agente && source .venv/bin/activate && source ~/obs/.env
      terminal
      cat > agente.py <<'EOF'
"""Agente de atendimento da Loja: loop de LLM com ferramentas, traces, métricas de negócio e chaos."""
import json, logging, os, random, threading, time
from fastapi import FastAPI
from pydantic import BaseModel
from openai import OpenAI
from opentelemetry import trace, metrics
from opentelemetry.trace import Status, StatusCode
from opentelemetry.instrumentation.openai_v2 import OpenAIInstrumentor
from telemetria import configurar
from ferramentas import FERRAMENTAS, executar

configurar("atendimento")
OpenAIInstrumentor().instrument()
tracer = trace.get_tracer("loja.agente")
meter = metrics.get_meter("loja.agente")
log = logging.getLogger("agente")

MODELO = os.getenv("LLM_MODEL", "openai/gpt-4.1-mini")
llm = OpenAI(base_url=os.getenv("LLM_BASE_URL"), api_key=os.getenv("LLM_API_KEY"))
PRECO_ENTRADA = float(os.getenv("PRECO_ENTRADA_1M", "0.40")) / 1e6   # USD por token
PRECO_SAIDA = float(os.getenv("PRECO_SAIDA_1M", "1.60")) / 1e6
PROMPTS = {
    "v1": ("Você é o agente de atendimento da Loja. Responda em português, em no máximo 3 frases. "
           "Use consultar_pedido para pedidos e buscar_politica para trocas, devoluções, frete e garantia. "
           "Nunca invente prazos ou valores: use só o que as ferramentas retornarem. "
           "Se não conseguir resolver, use abrir_chamado."),
    "v2": "Você é um atendente simpático. Responda rápido, sem enrolar.",
}
PROMPT_VERSAO = os.getenv("PROMPT_VERSAO", "v1")
CHAOS_LATENCIA = float(os.getenv("CHAOS_LATENCIA_S", "0"))
CHAOS_FALHA = float(os.getenv("CHAOS_FALHA_FERRAMENTA", "0"))

conversas = meter.create_counter("agente.conversas", unit="{conversa}", description="Conversas por resultado")
passos_h = meter.create_histogram("agente.passos", unit="{passo}", description="Chamadas ao LLM por conversa")
custo_c = meter.create_counter("agente.custo", unit="USD", description="Custo estimado em tokens")
ferr_c = meter.create_counter("agente.ferramenta.chamadas", unit="{chamada}", description="Chamadas de ferramenta")

app = FastAPI()


class Pergunta(BaseModel):
    texto: str



def chamar_llm(msgs, attrs):
    if CHAOS_LATENCIA:
        time.sleep(CHAOS_LATENCIA)
    r = llm.chat.completions.create(model=MODELO, messages=msgs, tools=FERRAMENTAS, temperature=0)
    custo_c.add(r.usage.prompt_tokens * PRECO_ENTRADA + r.usage.completion_tokens * PRECO_SAIDA, attrs)
    return r.choices[0].message


def chamar_ferramenta(chamada):
    nome = chamada.function.name
    with tracer.start_as_current_span(f"execute_tool {nome}") as s:
        s.set_attribute("gen_ai.operation.name", "execute_tool")
        s.set_attribute("gen_ai.tool.name", nome)
        s.set_attribute("gen_ai.tool.call.id", chamada.id)
        try:
            if random.random() < CHAOS_FALHA:
                raise TimeoutError("sistema de pedidos não respondeu")
            resultado = executar(nome, json.loads(chamada.function.arguments or "{}"))
            ferr_c.add(1, {"gen_ai.tool.name": nome, "status": "ok"})
        except Exception as e:
            s.record_exception(e)
            s.set_status(Status(StatusCode.ERROR, str(e)))
            ferr_c.add(1, {"gen_ai.tool.name": nome, "status": "erro"})
            log.error("ferramenta %s falhou: %s", nome, e)
            resultado = f"erro: {e}"
        return resultado


@app.post("/chat")
def chat(p: Pergunta):
    attrs = {"gen_ai.request.model": MODELO, "prompt.versao": PROMPT_VERSAO}
    with tracer.start_as_current_span("invoke_agent atendimento") as span:
        span.set_attribute("gen_ai.operation.name", "invoke_agent")
        span.set_attribute("gen_ai.agent.name", "atendimento")
        span.set_attribute("prompt.versao", PROMPT_VERSAO)
        trace_id = format(span.get_span_context().trace_id, "032x")
        log.info("pergunta recebida: %s", p.texto)
        msgs = [{"role": "system", "content": PROMPTS[PROMPT_VERSAO]}, {"role": "user", "content": p.texto}]
        usadas, observacoes = [], []
        try:
            for passo in range(1, 6):
                m = chamar_llm(msgs, attrs)
                if not m.tool_calls:
                    break
                msgs.append(m.model_dump(exclude_none=True))
                for chamada in m.tool_calls:
                    usadas.append(chamada.function.name)
                    saida = chamar_ferramenta(chamada)
                    observacoes.append(f"{chamada.function.name}: {saida}")
                    msgs.append({"role": "tool", "tool_call_id": chamada.id, "content": saida})
            else:
                raise RuntimeError("limite de 5 passos atingido")
        except Exception as e:
            span.record_exception(e)
            span.set_status(Status(StatusCode.ERROR, str(e)))
            conversas.add(1, {**attrs, "resultado": "falha"})
            log.error("conversa falhou: %s", e)
            return {"resposta": "Tive um problema agora. Tente de novo em instantes.", "ferramentas": usadas,
                    "trace_id": trace_id}
        resultado = "escalado" if "abrir_chamado" in usadas else "resolvido"
        span.set_attribute("agente.resultado", resultado)
        span.set_attribute("agente.passos", passo)
        conversas.add(1, {**attrs, "resultado": resultado})
        passos_h.record(passo, attrs)
        log.info("conversa %s em %d passos, ferramentas=%s", resultado, passo, usadas)
        return {"resposta": m.content, "ferramentas": usadas, "trace_id": trace_id}
EOF

    3.3

    KPIs com PromQL

    Conceito
    Capítulo 3 · O relatório

    Cinco números para a reunião de segunda

    Taxa de resolução, escalonamento, custo por conversa resolvida, latência p95 e satisfação. Todos sai do que já está sendo coletado.

    KPIs de um agente de atendimento

    KPIFórmulaQuem usa
    Taxa de resoluçãoresolvidas / totalnegócio
    Taxa de escalonamentoescaladas / totaloperações (fila humana)
    Custo por conversa resolvidacusto / resolvidasfinanças, FinOps
    Latência p95histogram_quantile(0.95, …)engenharia, experiência
    Passos por conversasoma passos / conversasengenharia (loops)
    Satisfaçãofeedback útil / total (Aula 04)produto

    Exercício 3.2

    Carga controlada e KPIs em PromQL

    ~35 min

    Gerar conversas variadas e calcular os KPIs no Grafana.

    1. Rode a carga (20 conversas, uma a cada 12 s ≈ 4 min). Se ainda não criou o carga.py, veja o exercício 2.4:

      terminal
      cd ~/obs/agente && source .venv/bin/activate && python carga.py 20 12

    2. No Explore → Prometheus, rode cada consulta:

      promql
      # latência p95 das chamadas ao LLM
histogram_quantile(0.95, sum by (le) (rate(gen_ai_client_operation_duration_seconds_bucket[5m])))
# tokens por minuto, entrada × saída
sum by (gen_ai_token_type) (rate(gen_ai_client_token_usage_sum[5m])) * 60
# taxa de resolução e de escalonamento
sum by (resultado) (rate(agente_conversas_total[15m])) / ignoring(resultado) group_left sum(rate(agente_conversas_total[15m]))
# custo por conversa (USD)
sum(rate(agente_custo_USD_total[15m])) / sum(rate(agente_conversas_total[15m]))
# custo por conversa RESOLVIDA
sum(rate(agente_custo_USD_total[15m])) / sum(rate(agente_conversas_total{resultado="resolvido"}[15m]))
# passos médios por conversa
sum(rate(agente_passos_sum[15m])) / sum(rate(agente_passos_count[15m]))
# taxa de erro das ferramentas
sum by (gen_ai_tool_name) (rate(agente_ferramenta_chamadas_total{status="erro"}[5m]))
    Resultado esperado
    • Taxa de resolução entre 60% e 90%; escalonamento nas perguntas de cobrança e produto quebrado.
    • Custo por conversa na casa de frações de centavo de dólar; custo por resolvida maior que por conversa.
    O que aprendemos com este exercício?
    • KPI é uma razão entre métricas: numerador e denominador precisam da mesma janela.
    • Custo por resolução expõe o custo das conversas que não resolvem.
