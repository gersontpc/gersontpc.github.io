O ensaio1.6 · game day

Ao final da aula você vai saber

  • Explicar o papel da observabilidade em DevOps e SRE
  • Definir SLA, SLO, SLI e error budget
  • Medir os 4 golden signals de uma API com OpenTelemetry e Prometheus
  • Montar e ler um dashboard de golden signals no Grafana
  • Comunicar um incidente com uma status page

No laboratório

  • Stack Prometheus + Grafana + API instrumentada com OpenTelemetry, via Docker Compose
  • Dashboard dos 4 golden signals como código (JSON)
  • Status page com monitoramento sintético (Uptime Kuma)
  • Falhas injetadas para ver o dashboard e a status page reagirem
