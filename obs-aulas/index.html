Antes da primeira aula · GitHub Codespaces e GitHub Models

Os exercícios rodam no navegador, num ambiente Linux com Docker e Python. O LLM vem do GitHub Models, gratuito para quem tem conta no GitHub. Não é preciso instalar nada.

1

Crie o codespace

Em github.com/codespaces, clique em New codespace (… → New with options) e escolha a máquina de 4 cores.

2

Valide o ambiente

Em Terminal → New Terminal:

terminal
docker version
python3 --version
3

Acesso ao LLM

O GitHub Models usa a API da OpenAI. No Codespaces, o GITHUB_TOKEN costuma bastar; se não, crie um token fine-grained com Models: read. O plano gratuito tem limite de requisições por minuto e por dia: os scripts de carga já respeitam esse ritmo.

Alternativas: Ollama local (sem conta, mais lento) ou qualquer chave compatível com a API da OpenAI.

4

Pare ao terminar

Ao fim de cada aula, em github.com/codespaces, use … → Stop codespace. A pasta ~/obs continua lá entre uma aula e outra.

Como usar esta página

Uma aba por aulaCada tópico traz primeiro os slides do conceito e, logo abaixo, o exercício daquele tópico.
Apresentar aulaProjeta os slides em tela cheia. Setas ← → navegam, Esc sai. Antes de cada exercício aparece o slide “Hora de praticar”.
Copiar comandosCada bloco de terminal tem o ícone de copiar no canto superior direito.
Um lab contínuoOs exercícios evoluem o mesmo agente em ~/obs, da Aula 01 à 05. Faça-os em ordem.
