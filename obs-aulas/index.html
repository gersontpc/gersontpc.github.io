Antes da primeira aula · GitHub Codespaces

Os exercícios rodam no navegador, num ambiente Linux com Docker já instalado. Não é preciso instalar nada na sua máquina.

1

Crie o repositório e o codespace

Em github.com/new, crie o repositório observability-stack com um README. Nele, clique em Code → Codespaces → … → New with options e escolha a máquina de 4 cores.

Cada aula ganha uma pasta no repositório (aula-1, aula-2…), commitada no fim do laboratório.

2

Valide o Docker

Em Terminal → New Terminal:

terminal
docker version
docker compose version
3

Acesse as ferramentas

Quando a stack subir, abra a aba Ports e clique no globo da porta: 3000 Grafana, 9090 Prometheus, 8000 API.

terminal
echo "https://${CODESPACE_NAME}-3000.${GITHUB_CODESPACES_PORT_FORWARDING_DOMAIN}"
4

Pare ao terminar

Ao fim de cada aula, rode docker compose down e, em github.com/codespaces, use … → Stop codespace. Antes de parar, commite e faça push do laboratório: o que está no GitHub não se perde, nem se o codespace for excluído.

Como usar esta página

Uma aba por aulaCada tópico traz primeiro os slides do conceito e, logo abaixo, o exercício daquele tópico.
Apresentar aulaProjeta os slides em tela cheia. Setas ← → navegam, Esc sai. Antes de cada exercício aparece o slide “Hora de praticar”.
Copiar comandosCada bloco de terminal tem o ícone de copiar no canto superior direito.
Acompanhar o progressoMarque os exercícios concluídos; o contador aparece na aba de cada aula. A marcação fica só no seu navegador.
