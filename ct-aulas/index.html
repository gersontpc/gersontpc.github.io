Antes da primeira aula · GitHub Codespaces

Todos os exercícios rodam no navegador, num ambiente Linux com Docker já instalado. Não é preciso instalar nada na sua máquina.

1

Crie o codespace

Acesse github.com/codespaces e clique em New codespace, ou, dentro de um repositório seu, em Code → Codespaces → Create codespace.

Escolha a máquina de 4 cores (…→ New with options): as aulas de Kubernetes precisam de mais memória.

2

Abra o terminal e valide

O VS Code abre no navegador. Vá em Terminal → New Terminal e confira se o Docker responde:

terminal
docker version
docker run --rm hello-world
3

Acesse as aplicações

Quando um container publicar uma porta (ex.: -p 8080:80), abra a aba Ports e clique no ícone de globo. A URL também pode ser gerada no terminal:

terminal
echo "https://${CODESPACE_NAME}-8080.${GITHUB_CODESPACES_PORT_FORWARDING_DOMAIN}"
4

Pare ao terminar

O Codespaces consome horas da sua cota. Ao fim de cada aula, em github.com/codespaces, use … → Stop codespace. Exclua o codespace quando terminar a disciplina.

Arquivos em ~/labs continuam lá entre uma parada e outra; só se perdem ao excluir o codespace.

Na AWS · AWS Academy Learner Lab

ECS e EKS no AWS Academy Learner Lab

Para provisionar o Amazon ECS e o Amazon EKS vamos usar o AWS Academy Learner Lab: uma conta AWS de estudo, com créditos da turma, sem cartão de crédito e sem custo para você. O convite chega por e-mail do AWS Academy.

  1. Aceite o convite e entre em awsacademy.instructure.com → Modules → Launch AWS Academy Learner Lab.
  2. Clique em Start Lab e aguarde o indicador ao lado de “AWS” ficar verde.
  3. Em AWS Details → AWS CLI: Show, copie as credenciais temporárias para ~/.aws/credentials no Codespaces e confira com aws sts get-caller-identity.
Antes de usar, saiba que
  • A sessão dura cerca de 4 horas e as credenciais expiram junto: ao reiniciar o lab, copie-as de novo.
  • Os recursos continuam existindo depois que a sessão acaba e consomem os créditos. Apague tudo no fim do exercício.
  • As permissões de IAM são limitadas: use a role pronta LabRole em vez de criar roles novas.
  • Trabalhe na região us-east-1.
